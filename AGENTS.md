# AGENTS.md

## Commands

Always use `bun --bun run` (Bun runtime), not `bun run`:

```bash
bun --bun run dev       # Dev server on :3000
bun --bun run build     # Production build
bun --bun run test      # Vitest (single run)
bun --bun run test --watch  # Watch mode
bun --bun run lint      # ESLint
bun --bun run format    # Prettier check
bun --bun run check     # Prettier + ESLint auto-fix (run before committing)
```

**Test filtering:** `bun --bun run test -- -t "test name pattern"` (Vitest filters via `-t`).

## Architecture

TanStack Start full-stack React app. Vite 8, React 19, Tailwind v4, shadcn/ui (New York + lucide), DaisyUI, Nitro server.

- `src/router.tsx` - TanStack Router setup (QueryClient context, SSR query integration)
- `src/routes/` - File-based routes → auto-generates `src/routeTree.gen.ts` (never edit this file)
- `src/features/<name>/` - Self-contained business domains (components, hooks, api, types, index.ts barrel)
- `src/shared/components/ui/` - shadcn primitives
- `src/shared/lib/` - Utilities (`cn()` helper)
- `src/integrations/` - Third-party setup (TanStack Query provider)
- `src/styles.css` - Tailwind v4 `@theme inline` config, shadcn CSS vars, custom design tokens, DaisyUI plugin

## Path aliases

Primary alias is `#/*` → `./src/*`. Also `@/*` → `./src/*`. Always import from feature barrels:

```ts
import { useAppForm } from '#/features/demo' // correct
import { useAppForm } from '#/features/demo/hooks/...' // wrong - deep import
```

## Route generation

New routes require dev server restart or `bun --bun run check` to regenerate `routeTree.gen.ts`. Routes use `createFileRoute` from `@tanstack/react-router`. The root route (`__root.tsx`) wraps all pages via `shellComponent` and includes the dark mode inline script for flash-free theme initialization.

## TypeScript

- `strict: true`, `noUnusedLocals: true`, `noUnusedParameters: true`, `verbatimModuleSyntax: true`
- Use `import type` for type-only imports (required by `verbatimModuleSyntax`)
- `jsx: "react-jsx"` — no need to import React in JSX files
- Never use default parameter values

## Styling

- Tailwind v4 CSS config (no tailwind.config.ts). Theme tokens in `src/styles.css` via `@theme inline`
- shadcn CSS variables use `oklch()` wrapped in var() references (e.g. `--color-primary: var(--primary)`)
- Dark mode: `@custom-variant dark (&:is(.dark *))` in CSS, `.dark` class on `<html>`, localStorage key `theme`
- Custom design tokens: `--sea-ink`, `--lagoon`, `--palm`, `--sand`, `--foam`, `--surface`, `--line`, `--bg-base`
- Custom utility classes: `.island-shell`, `.feature-card`, `.page-wrap`, `.display-title`, `.rise-in`, `.nav-link`
- DaisyUI is also loaded as a `@plugin` — conflicts with shadcn styling are possible on overlapping components

## shadcn/ui

- Add components: `bun x shadcn@latest add <name>` (not `pnpm dlx` — this is a Bun project)
- Components go to `src/shared/components/ui/` (configured in `components.json`)
- Icon library: `lucide-react` (verified in `components.json` `iconLibrary: "lucide"`)
- New York style, CSS variables mode, zinc base color
- Uses `cn()` from `#/shared/lib/utils` (clsx + tailwind-merge)

## Forms

TanStack Form + Zod. Use the demo feature's `useAppForm` pattern: `form.AppField` + `field.TextField` with Zod validators. The demo feature in `src/features/demo/` serves as reference implementation for form components.

## State management

- **Server state**: TanStack Query (QueryClient provided via router context in `src/integrations/tanstack-query/root-provider.tsx`)
- **Client state**: Zustand
- **Theme**: localStorage + inline script in `__root.tsx` (avoids hydration flicker)

## Git workflow

- Conventional Commits enforced by commitlint (e.g. `feat:`, `fix:`, `chore:`)
- Pre-commit hook runs `bun lint && bun format` — lint must pass to commit
- Prettier: no semicolons, single quotes, trailing commas
